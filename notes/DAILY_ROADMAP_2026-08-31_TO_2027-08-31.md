# Daily Technical Roadmap: 2026-08-31 to 2027-08-31

## How to use this calendar

Do today's line and stop at its time limit. A task marked **school first** is optional if coursework needs the block. A **freeze** means no prep debt is created.

Labels:

- **P** — Python interview problem solving
- **B** — the one active book
- **L** — C++ or Rust language fluency
- **X** — inference service or a real AFRL/Sator transfer task
- **A** — internship application materials or applications
- **M** — timed mock/interview explanation
- **R** — review, plan, or rest

For every new **P** problem: 25 minutes unaided, then implement/tests/complexity. A redo is from a blank file without reading the old solution. Friday application blocks target Spring/Summer 2027 SWE roles and intentionally include ML/AI systems, infrastructure, inference, distributed systems, and protocol infrastructure; they do not exclude strong general SWE roles.

The calendar uses the [official 2026–27 CUNY dates](https://www.cuny.edu/academics/academic-calendars/) available on 2026-08-31: Fall term began 2026-08-28, Fall finals are 2026-12-15 through 2026-12-21, Spring classes begin 2027-01-28, Spring recess is 2027-04-21 through 2027-04-29, and Spring finals are 2027-05-21 through 2027-05-27. The user's personal first class day is treated as 2026-09-01. If a professor's actual exam/project schedule is heavier, the school-first rule overrides this file.
